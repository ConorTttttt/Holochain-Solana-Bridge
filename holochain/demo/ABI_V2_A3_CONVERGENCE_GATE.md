## Proposed safest contract direction (requires actual A3 + independent A5 sign-off)

1. Keep A3's original `source/verifiedEvidence`, complete `proof` raw transaction and block and both snapshots **as immutable, lossless authenticated-source commitments**, including literal four denials. Do not squeeze signed proof down to A4's digest-only `WitnessV2`.
2. Independently define the `AuditObservationV2` Rust `#[hdk_entry_helper]` typed entry with `deny_unknown_fields`, exact safe integer/decimal-u64/b58/hex rules, strict size quotas, supported RPC transaction versions, source scope and DHT operation validation. A separate A4 append-only record type must not alias v1. Choose a typed representation preserving original bytes; a generic deserialized `serde_json::Value` **cannot be a substitute** for strict typed permission checks. Recompute cryptographic commitments at the trusted **admission** boundary.
3. Keep A3's `witnessDigest` domain unchanged. If necessary, derive a distinct A4 **`destinationBindingDigest`** over the exact canonical original witness digest, source identity, verified runtime destination, build+ABI fingerprints, and literal denials with a separately published domain; never claim two incompatible domains are equivalent.
4. Require explicit `sourceCodeCommit`, generated IDL/ELF, signed initialization `holochainScope`, durable Observation ledger identity and deploy epoch. A2 SOL #55 provides fresh source-signed scope, but source-authenticated immutable epoch policy remains a separate review item.
5. A4 HAM adapter only talks to its independently installed demo app; `LairCredentials::Node`, `CapGrantOptIn::Withheld`, exact allowlisted signed role/zome/function, preflight full CellId and source admission. `read` must revalidate actual `ActionHash`, every field, source and destination scope; `uncertain` outbox must read before any retry and HOLD ambiguity. Hostile rollback remains unprotected.
6. Implement `record_observation_v2` **only after** A3 approves the exact field table and canonical literal byte vector, and Agent 5 independently approves immutable Holochain source SHA, complete lock graph, compiled native+WASM hashes, DNA/hApp hashes, `hc dna hash`, installed app/full CellId/agent, external signer, tuple, payload bytes/digest, read-only negative matrix and allowed operation. Absence of any element means **NO SIGNED WRITE**.
7. Always refuse caller-controlled `observer_reviewed_outbox` and economic grants. Keep `creditEligible:false`, `independentConsensusVerified:false`, `spendableBaseUnits:"0"`, `withdrawalAuthorized:false`. No refund v1/v2, credit, withdrawal, published Unyt coordinator or main merge.

**Required reply from A3:** exact canonical full real v2 `unsigned` bytes and expected digest produced on one source-equivalent Kit+validator SHA, plus explicit typed field list and mandatory size bounds. **Required reply from A5:** separate review of producer admission, Holochain caller capability, digest construction, domain epoch, replay/rollback and source-to-ActionHash threat model, with any eventual authorization scoped to the exact installed identity.
