## Independently authenticated recovery: explicit P0 stop

The current JSON ledger is crash-consistent with exclusive lock, fsync+rename and SHA-256 fingerprints, **not authenticated against a filesystem administrator**. A malicious actor can replace checkpoint+blockhash, change balances while recomputing SHA-256, restore a valid older snapshot, truncate the ledger, or make two independent ledgers both accept the same deposit. This is **not fixed in this change**; no reviewed, access-separated attestor has been deployed.

Proposed review-only domain-separated `OBS_CHECKPOINT_V1` canonical CBOR/RFC-8785 structure: version, genesis, program, deployment epoch/slot, source commit, IDL/ELF digests, mint and scope, highest fully scanned slot and blockhash, previous external checkpoint hash, monotonic sequence number, deterministic Merkle/ledger root of sorted `deposit id + occurrence + digest + refund lifecycle`, independent provider/validator provenance, witness keyset epoch, and all four literal denial fields. Sign with quorum of **off-host independent keys**, publish under access-separated append-only immutable retention and independently retrieve the latest authenticated sequence before any restart. Crash before anchor publication leaves a provisional cursor; roll back by **verified external replay**, not by trusting a locally advanced cursor. Forked anchors, equivocation, stale keys, missing quorum, conflicting ledgers, deleted/rolled-back state, missing archives or unresolved refunds all HALT; refuse skip-ahead.

Acceptance tests required after independent review: unauthorized edit with recomputed SHA, fully valid rollback, forward forgery, deletion/truncation, reorder, stale-lock compromise, crash between local fsync/rename/external publication, key rotation and revocation, witness disagreement, duplicate global acceptance in two ledgers, and recovery when provider history contradicts the anchored head. A local HMAC with its secret on the compromised host, or a threshold signature over unverified RPC assertions, does **not** confer independent Solana consensus or economic authorization.
